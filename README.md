# 🌸 벚꽃 캐치캐치

웹캠 앞에서 손가락을 움직여 떨어지는 벚꽃을 터치하는 게임입니다.
MediaPipe Hand Landmarker로 손끝을 인식하며, HTML 파일 하나로 동작합니다.

## 실행

- 웹: https://parkchan70.github.io/cherry-blossom-catch/
- 로컬: `index.html` 을 브라우저에서 열기 (카메라는 `https://` 또는 `localhost` 에서만 켜집니다)

인터넷 연결이 필요합니다 (손 인식 모델을 내려받습니다).

## 놀이 방법

1. 제한 시간(15 / 30 / 60초)을 고르고 **게임 시작**
2. 카메라 권한을 허용하면 3·2·1 카운트다운 후 시작
3. 손끝(엄지~새끼, 두 손 가능)으로 벚꽃을 터치하면 10점
4. 오른쪽 위 🔊 버튼으로 효과음을 끄고 켤 수 있습니다

다른 탭으로 이동하면 자동으로 일시정지되고, 돌아오면 카운트다운 후 이어서 진행됩니다.
